## 📁 ARCHIVOS DEL PROYECTO

* [`index.html`](index.html): Aplicación web completa de una sola página (PWA). Incluye optimización móvil con barra de acción fija para el pulgar, metadatos OpenGraph con foto real, Schema.org estructurado (`ProfessionalService` y `FAQPage`), y el **Escáner de Lealtades Inconscientes de 3 pasos**.

* [`verify_draft.py`](verify_draft.py): Suite automatizada de verificación de sanidad y cumplimiento de calidad (Schema.org, OpenGraph, Zero-PII, HTTP 200).

* [`index.html.txt`](index.html.txt): Respaldo de texto previo.

## 🚀 FUNCIONALIDADES CLAVE IMPLEMENTADAS

1. **Escáner Interactivo de Lealtades Familiares (Lead Magnet):**
   * Paso 1: Identificación del área de bloqueo recurrente (Dinero y Éxito, Pareja y Relaciones, o Bienestar y Síntomas Físicos).
   * Paso 2: Vivencia del clan familiar asociada (quiebras, despojos, soledad, secretos).
   * Paso 3: Emoción inconsciente disparada (culpa por destacar, miedo a no pertenecer, lealtad invisible).
   * **Resultado personalizado:** Redacta un diagnóstico preliminar y genera un botón directo de WhatsApp prellenado con el caso exacto del consultante.
2. **Detección Dinámica de Procedencia (UTMs):**
   * El script detecta si el usuario llegó desde Instagram, TikTok o Facebook, y ajusta automáticamente el saludo inicial de WhatsApp para que César sepa de inmediato qué canal trajo al paciente.
3. **Aviso Legal & Ético Riguroso:**
   * Clarificación explícita de que la desprogramación evolutiva es un acompañamiento de bienestar y desarrollo personal que no sustituye tratamientos médicos, psicológicos o psiquiátricos.
